## About

I’m **Aman Vishwakarma**, a Computer Science Engineering student specializing in **Artificial Intelligence & Machine Learning**, with a strong focus on software engineering and product development.

I enjoy building software that is not only functional, but also **structured, maintainable, performant, secure, and useful to real users**. My work spans full-stack development, data-driven applications, AI/ML experimentation, responsive interfaces, and product-oriented engineering.

My engineering approach is simple: understand the problem deeply, design the right abstraction, build deliberately, validate continuously, and ship a product that solves the intended problem.

- **Software Engineering:** Data Structures & Algorithms, OOP, modular architecture, clean implementation
- **AI/ML:** Data analysis, predictive modeling, computer vision, intelligent application development
- **Full Stack Development:** Responsive interfaces, application logic, APIs, databases and deployment workflows
- **Product Engineering:** UX-aware architecture, iteration, usability, performance and maintainability
- **Engineering Mindset:** Problem solving, continuous learning, reusable systems and practical execution
